# 🛒 Ecommerce Full Stack (MERN Stack)

A full-stack ecommerce web application built using **React (Vite)** for the frontend and **Node.js / Express / MongoDB** for the backend.  
The project includes authentication, admin dashboard, product management, cart system, and PayPal payment integration.

---

## 🚀 Features

### 👤 User Features
- User registration & login (JWT Authentication)
- Browse products with filters (category / gender)
- Add products to cart
- Checkout using PayPal
- View order history
- User profile management

### 🛠️ Admin Features
- Admin dashboard
- Add / update / delete products
- Manage users (change role: admin/customer)
- Manage orders
- Upload product images using Cloudinary

---
